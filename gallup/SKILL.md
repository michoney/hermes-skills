# 盖洛普优势识别器 (CliftonStrengths)

基于盖洛普《StrengthsFinder 2.0》(Don Clifton 发明)，34 项天赋主题。核心思想：**人有 34 种先天倾向，找到你的前五优势并发挥它，而不是补短板。**

## 核心原则

1. **扬长避短，不补短板** — 把精力放在天赋上，短板只需要"够用"，不需要"变强"
2. **天赋 ≠ 优势** — 天赋(天生的思维/感受/行为模式) + 投入(知识/技能/练习) = 优势
3. **前五主题** — 每个人有 5 个最突出的主题，是你的核心驱动力
4. **主题无好坏** — 每种主题都有光和影，关键是场景匹配
5. **团队互补** — 团队里不同主题搭配，比同质化更强

## 34 项主题速查（按领域分）

### 执行力领域 (Executing)
| 主题 | 定义 |
|------|------|
| **Achiever 成就** | 每天从零开始，必须有具体成就才满意；持续的内驱力 |
| **Arranger 统筹** | 善于管理复杂局面的所有变量，像指挥家一样调配 |
| **Belief 信仰** | 有持久的核心价值观，用它指导一切决策 |
| **Consistency 公平** | 强烈需要平等待人，不看身份地位，规则一致 |
| **Deliberative 审慎** | 谨慎、警觉、深思熟虑，预先看到风险 |
| **Discipline 纪律** | 世界需要可预测、有条理，本能地建立秩序和习惯 |
| **Focus 专注** | 每天问"我要去哪"，需要清晰目标，否则迷失 |
| **Responsibility 责任** | 对承诺的事心理上完全负责，说到做到 |
| **Restorative 排难** | 热爱解决问题，遇到故障反而被激发能量 |

### 影响力领域 (Influencing)
| 主题 | 定义 |
|------|------|
| **Activator 行动** | "什么时候能开始？"对行动不耐烦，只有行动才算数 |
| **Command 统帅** | 天生愿意主导，不介意把观点强加于人 |
| **Communication 沟通** | 喜欢解释、主持、演讲、写作，把想法讲得生动 |
| **Competition 竞争** | 以比较为驱动，本能地感知他人的表现 |
| **Maximizer 完美** | 以卓越为标尺，从平庸到优秀不满足，追求顶尖 |
| **Self-Assurance 自信** | 内心坚信自己能行，靠内在标准判断 |
| **Significance 追求** | 想在他人眼中很重要，要被认可、被听见 |
| **Woo 取悦** | 享受结识陌生人并赢得他们好感的挑战 |

### 关系建立领域 (Relationship Building)
| 主题 | 定义 |
|------|------|
| **Adaptability 适应** | 活在当下，未来是选择创造出来的，随遇而安 |
| **Connectedness 关联** | 万物皆有因，深信彼此相连，意义感强 |
| **Developer 伯乐** | 总能看到他人潜能，认为没人已定型 |
| **Empathy 体谅** | 能感知身边人的情绪，仿佛感同身受 |
| **Harmony 和谐** | 寻求共识，把冲突和摩擦降到最低 |
| **Includer 包容** | "把圈子扩大"，让每个人有归属感 |
| **Individualization 个别** | 对每个人独特的品质着迷，反感贴标签 |
| **Positivity 积极** | 慷慨赞美、常带微笑，总能发现积极面 |
| **Relator 交往** | 倾向深交已知的人，关系由浅入深 |

### 战略思维领域 (Strategic Thinking)
| 主题 | 定义 |
|------|------|
| **Analytical 分析** | "证明给我看"，质疑一切声称，讲逻辑 |
| **Context 回顾** | 往回看，答案在过去，用历史理解当下 |
| **Futuristic 前瞻** | "要是...就好了"，喜欢眺望地平线，未来牵引 |
| **Ideation 理念** | 被概念迷住，痴迷于"最佳解释"的发现 |
| **Input 搜集** | 好奇，收集信息/事实/书籍/语录，多多益善 |
| **Intellection 思维** | 喜欢思考、脑力活动，独自时最专注 |
| **Learner 学习** | 热爱学习本身，过程就是奖励 |
| **Strategic 战略** | 在杂乱中找到最佳路径，天生会排序 |

## 使用方法

### 识别一个人的优势
根据行为描述推断其可能的前五主题：
1. 听 TA 反复说的句式（"什么时候开始？"→Activator；"证明给我看"→Analytical）
2. 看 TA 消耗/恢复能量的方式（独处→Intellection；社交→Woo）
3. 看 TA 对什么不耐烦（过程→Activator；平均→Maximizer）
4. 看 TA 的情绪模式（乐观→Positivity；谨慎→Deliberative）

### 输出格式（给超哥评估学员/员工/合作者）
```
优势画像: <3-5个最可能的主题>

核心驱动: <1句解释这个人的能量来源>

建议:
- 发挥: <怎么用他的天赋>
- 避开: <什么场景会让他耗竭>
- 搭配: <适合配什么类型的搭档>
```

### 团队搭配
- 创新任务: 理念(Ideation) + 前瞻(Futuristic) + 行动(Activator)
- 交付任务: 纪律(Discipline) + 责任(Responsibility) + 成就(Achiever)
- 客户关系: 体谅(Empathy) + 取悦(Woo) + 积极(Positivity)
- 风险控制: 审慎(Deliberative) + 分析(Analytical) + 排难(Restorative)
- 忌讳: 全是战略思维的团队没人执行；全是执行的团队没人想方向

## 边界

- 不给人贴"好坏"标签，只描述行为模式
- 不替代专业测评（正式测试需 gallup.com 购买码），本 skill 是行为推断
- 场景适配最重要：同一种主题在不同岗位价值完全不同
